# НашеПО · Поиск для Топоматик 360

Версия 0.2.1. Сквозной поиск по всему проекту. Введите любое значение, и плагин найдёт элементы во всех моделях проекта и подключённых вложений, подсветит их и переведёт камеру. Знать, в каком файле и в каком свойстве лежит значение, не нужно.

## Установка

Адрес плагина:

    https://borismoniac.github.io/360.info/

В настольном Топоматик 360 откройте **Плагины → Установить плагин**, вставьте этот адрес и подтвердите установку. После первой установки перезапустите приложение. В веб-версии обновите страницу.

[**Открыть установку в веб-версии Топоматик 360**](https://360.topomatic.ru?extensionInstallPath=https%3A%2F%2Fborismoniac.github.io%2F360.info%2F)

## Как пользоваться

Панель живёт в левом блоке **НашеПО**, вкладка **Поиск**. Открыть её можно и кнопкой **Поиск** на вкладке ленты **НашеПО**.

- Введите значение и нажмите **Найти** или Enter. Поиск идёт по имени элемента, по пути в дереве, по имени типа и по всем названиям и значениям свойств. Предела на число находок нет.
- **Подсветить все** выделяет сразу все находки и подгоняет камеру под них.
- Стрелки **←** и **→** переходят по находкам по одной, камера следует за выбранным элементом.
- Щелчок по строке списка подсвечивает этот элемент и переводит к нему камеру.
- **Снять** убирает подсветку.

Кнопка **Быстрый поиск** на ленте спрашивает значение и сразу подсвечивает все совпадения, без открытия панели.

## Свойства элемента

Под списком находок лежит блок **Свойства элемента**. Он показывает все свойства выбранной строки: имя, модель, путь и весь набор из модели. Переключаться на штатную панель свойств не нужно, поэтому запрос и список находок не теряются.

Поле **фильтр свойств** оставляет только строки, где искомое встречается в названии или значении свойства. Заголовок блока сворачивает его, когда нужно больше места под список.

## Условия отбора

Блок **Условия отбора** сужает уже найденное, не запуская поиск заново. Кнопка ＋ добавляет условие.

Условие состоит из свойства, оператора и значения. В списке свойств собраны все свойства, встретившиеся в находках, плюс имя, модель и путь. Вариант **любое свойство** проверяет условие по всем значениям сразу.

Операторы: содержит, не содержит, равно, не равно, больше, меньше, заполнено, пусто. Числовые сравнения работают и с запятой в качестве разделителя.

Условия складываются: элемент остаётся в списке, только если проходит все. Список пересобирается сразу при изменении любого условия.

Пока значение не введено, условие не применяется и подсвечивается подсказкой. Иначе список пустел бы сразу после выбора оператора. Для сравнений «больше» и «меньше» число вынимается из текста, поэтому значения вида «1 200,5 мм» сравниваются правильно.

## Настройки поиска

- **Учитывать регистр** включает точное совпадение регистра букв.
- **Искать в скрытых** добавляет к поиску скрытые вложения. По умолчанию они пропускаются, как и в штатных фильтрах программы.

## Как это устроено

Элементы моделей IFC и SMDX попадают в чертёж как слои с типизированными свойствами. Плагин обходит слои главного чертежа и чертежей всех загруженных вложений, сравнивая запрос с именем, путём, типом и всеми свойствами.

Подсветка и перевод камеры выполняются тем же механизмом, что и штатные фильтры в дереве проекта: у слоя чертежа активного вида вызывается `selectLayers` с найденным набором слоёв.

Разбор свойств ограничен по глубине вложенности и по числу узлов на слой, а обход периодически отдаёт управление интерфейсу. Поэтому поиск по тяжёлой модели не подвешивает программу. Полный набор свойств читается только для найденных элементов, а не для всей модели.

## Общий блок «НашеПО»

Контейнер панелей `nashepo` объявлен в этом плагине, но собирает панели всех плагинов. Любой другой плагин может добавить свою панель в этот же блок, указав в манифесте `"container": "nashepo"`. Так все инструменты собираются в одном месте слева.

Вкладка ленты `nashepo_tools` работает так же: каждый плагин добавляет в неё свою группу кнопок.

А вот верхнее меню объединяется только по полю `role`, которое уходит в системное меню окна. Нестандартное значение там рискованно, поэтому у каждого плагина своё меню с собственным названием: **НашеПО · Поиск** и **НашеПО · Проект**.

## Сборка

```sh
npm install
npm run build
```

Сборка попадает в `dist/` и копируется в `docs/`, откуда её публикует GitHub Pages. Отладка — `npm run serve`, проверка типов — `npm run typecheck`.
